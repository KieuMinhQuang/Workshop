### Mục tiêu tuần 8:

* Tìm hiểu Docker và quy trình triển khai ứng dụng trên môi trường Container kết hợp với các dịch vụ AWS.
* Thực hành đóng gói và triển khai ứng dụng Frontend, Backend bằng Docker trên máy local và Amazon EC2.
* Tìm hiểu và thực hành sử dụng Amazon RDS để quản lý cơ sở dữ liệu, Amazon ECR và Docker Hub để lưu trữ, quản lý Docker Image.
* Sử dụng Docker Compose để quản lý và triển khai nhiều Container, kiểm tra hoạt động của ứng dụng trên môi trường AWS.

### Kết quả đạt được tuần 8:

* Hiểu được nguyên lý hoạt động của Docker, Container và quy trình triển khai ứng dụng Frontend, Backend trên môi trường local.
* Thực hành cấu hình hạ tầng AWS gồm VPC, Security Group, IAM Role, EC2 Instance và Amazon RDS.
* Nắm được cách cài đặt, cấu hình Docker trên EC2 và kết nối ứng dụng với cơ sở dữ liệu RDS.
* Thực hành đóng gói, triển khai ứng dụng bằng Docker Image và quản lý nhiều Container thông qua Docker Compose.
* Hiểu và thực hành sử dụng Amazon ECR, Docker Hub để lưu trữ, quản lý và chia sẻ Docker Image.
* Nắm được quy trình kiểm tra ứng dụng và dọn dẹp tài nguyên AWS sau khi hoàn thành Workshop.
