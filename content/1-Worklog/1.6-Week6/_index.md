### Week 6 Objectives:

* Explore AWS IAM Identity Center and learn how to manage identities and access permissions centrally across multiple AWS accounts.
* Gain hands-on experience with AWS Organizations, Organizational Units (OUs), users, groups, and permission sets to organize and manage access.
* Study the AWS CLI, SSO authentication mechanisms, temporary credentials, and advanced permission policies.
* Learn how to automate user and group management using the IAM Identity Center Identity Store APIs with Python Boto3.

### Outcomes for Week 6:

* Understood the roles of AWS Organizations and IAM Identity Center in the centralized management of multiple AWS accounts.
* Learned how to organize accounts using Organizational Units, manage Users and Groups, and assign permissions via Permission Sets.
* Practiced authenticating with the AWS CLI using SSO, and gained an understanding of temporary credentials and the "Switch Role" mechanism between accounts.
* Learned how to configure time-bound access and utilize Customer Managed Policies to control access to resources.
* Gained proficiency in using Identity Store APIs with Python Boto3 to automate the management of users, groups, and memberships within the IAM Identity Center.
