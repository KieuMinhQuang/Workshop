### Week 7 Objectives:

* Explore AWS Backup and learn how to build an automated data backup and recovery system on AWS.
* Practice creating a Backup Plan, configuring a Backup Vault, and setting up backup schedules for AWS resources.
* Learn to integrate AWS SNS and AWS Lambda to automate the processes of notification, verification, and data recovery.
* Verify backup/restore results and learn the procedures for managing and cleaning up resources after completing the exercises.

### Outcomes for Week 7:

* Understood the role of AWS Backup in managing and automating data backup and recovery processes.
* Gained hands-on experience in creating S3 buckets and using CloudFormation to deploy the infrastructure required for a backup system.
* Learned how to create backup plans, configure backup rules and backup vaults, and assign resources for backup.
* Understood and practiced integrating AWS SNS and AWS Lambda to automate notifications and monitor backup/restore processes.
* Learned how to verify recovery results via CloudWatch Logs and perform cleanup of AWS resources upon completion of the workshop.
