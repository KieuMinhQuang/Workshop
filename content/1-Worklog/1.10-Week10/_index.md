### Week 10 Objectives:

* Explore the process of automating application builds and deployments on AWS using the CI/CD model.
* Understand the roles of—and how to coordinate—AWS CodeStar, CodeCommit, CodeBuild, CodePipeline, and CodeDeploy.
* Gain hands-on experience connecting the Eclipse IDE development environment to AWS CodeCommit and deploying a Java application to Elastic Beanstalk.
* Learn how to deploy, monitor, and manage Windows Services on EC2 instances using AWS CodeDeploy.

### Achievements for Week 10:

* Gained an understanding of the CI/CD process and the role of AWS Developer Tools in automating application development and deployment.
* Learned how to create a CodeStar project, manage source code using CodeCommit, and connect it to an Eclipse IDE development environment.
* Understood the process of committing and pushing source code, and how CodePipeline automatically executes the Source, Build, and Deploy stages.
* Learned how to deploy Java applications to an Elastic Beanstalk environment and how to troubleshoot errors during the deployment process.
* Learned how to use AWS CodeDeploy to deploy a Windows Service to an EC2 instance, store deployment packages in S3, and monitor deployment status.
