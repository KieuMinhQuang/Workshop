# BLOG 2: BUILDING A METERING SYSTEM FOR SAAS ON AWS ​​MARKETPLACE USING METERING AGENT SKILL

### Leveraging AI Agents and AWS Serverless to Automate SaaS Usage Tracking

Hello everyone! Today, I’d like to share an intriguing AWS solution that utilizes AI Agents in the development of SaaS systems. The "AWS Marketplace Metering Agent Skill" helps developers build, deploy, and test systems for tracking service usage, thereby enabling more accurate customer billing.

#### 3.2.1 The Challenge

For SaaS products listed on AWS Marketplace, businesses need to track the volume of resources or services consumed by customers in order to implement usage-based billing.

However, building a custom metering system from scratch involves handling numerous complexities—such as customer registration, usage data collection, data aggregation, and the submission of billing information—which makes the development process both complicated and time-consuming.

#### 3.2.2 The AWS Solution

![SaaS Metering System Architecture on AWS Marketplace](/images/blog2/saas-metering-architecture.png)

*Figure 3.2: Architecture of the SaaS usage metering system on AWS Marketplace.*

AWS has introduced the "Metering Agent Skill," a tool designed to assist AI agents in building SaaS metering systems directly within an AI-integrated development environment.

The solution operates through several key components:

- **AI Agent and AWS MCP Server:** Facilitate the retrieval of guidance, analysis of requirements, and generation of integration code.
- **AWS SAM and CloudFormation:** Automate the creation and deployment of necessary AWS resources.
- **Amazon API Gateway and AWS Lambda:** Handle customer registration information and process data.
- **Amazon EventBridge and Amazon SQS:** Manage event orchestration, scheduling, and the transmission of usage data.
- **Amazon DynamoDB:** Store customer information, licenses, and usage data.
- **BatchMeterUsage API:** Submit usage data in batches to AWS Marketplace for billing purposes.

#### 3.2.3 Why is this approach effective?

A standout feature of this solution is the use of an AI agent to automate various stages of system development. Instead of manually writing all the source code and configuring each individual AWS service, developers can simply describe their requirements, and the agent will assist in generating the necessary code and deployment templates.

Furthermore, the system supports a "dry-run" testing mode, allowing for the verification of workflows without actually submitting live billing data. This helps mitigate risks before the system goes into production.

#### 3.2.4 Implementation considerations

To utilize the Metering Agent Skill, developers must have an AWS Marketplace Seller account and a SaaS product configured with a usage-based billing model.

Additionally, any source code generated by the AI ​​should be reviewed for security and compliance before being deployed in a production environment. Enterprises also need to implement the logic for recording SaaS application usage data into DynamoDB themselves, as this component is not automatically deployed by the Agent.

#### 3.2.5 Personal Assessment & Conclusion

In my view, this is a valuable solution for businesses developing SaaS products on AWS Marketplace. Combining an AI Agent with serverless services simplifies the process of building a metering system and reduces the need for manual configuration.

Through this article, I have gained a better understanding of how to integrate Amazon EventBridge, AWS Lambda, Amazon SQS, and DynamoDB to build an event-driven data processing system. Furthermore, I have come to appreciate the role of an AI Agent in assisting with the programming and deployment of real-world applications on a cloud computing platform.
